# NoBrainer Data Architecture v1

Ziel: bestehende Balance- und Content-Daten aus v0.13.10 tabellarisch pflegen, beim Build validieren und in TypeScript-Datenmodule generieren. Gameplay und Save-Format bleiben in Phase 1 unverändert; bestehende IDs werden übernommen und Namensreferenzen erst in einer späteren Phase schrittweise auf IDs migriert.
